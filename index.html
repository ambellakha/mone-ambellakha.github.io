Seven Traps

Seven exercises built from real-world anti-patterns. Each opens a full React project in StackBlitz — no install, no account. The buggy code is pre-loaded. Your job: find what's wrong and fix it. The TRAINING.md file in each project contains the scenario, the trap, and hints.

How it works → Click "Open in StackBlitz" on any exercise. A React playground opens in a new tab with the broken component already loaded. Read TRAINING.md first, then fix src/Exercise.jsx. The preview updates live. When the component renders without double-renders or console warnings, you've got it.
